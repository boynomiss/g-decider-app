# 🔑 Step-by-Step: Enable Google APIs for Real Place Images

## Follow These Exact Steps:

### Step 1: Open Google Cloud Console

**Click this link:** https://console.cloud.google.com/

- Log in with your Google account
- You should see your dashboard

---

### Step 2: Find Your Project

Look at the top of the page for a dropdown that shows your project name.

**Your API key belongs to a project. Click the dropdown and:**
- Look for: `g-decider-backend` OR
- Look for: `g--decider-app` OR  
- Any project name related to your app

**Select that project.**

---

### Step 3: Go to APIs Library

**Click this direct link:** https://console.cloud.google.com/apis/library

Or from the console:
1. Click the hamburger menu (☰) on the left
2. Click **"APIs & Services"**
3. Click **"Library"**

---

### Step 4: Enable Maps Static API

**In the search box at the top:**
1. Type: `Maps Static API`
2. Click on **"Maps Static API"** (should be first result)
3. Click the blue **"ENABLE"** button
4. Wait for it to enable (shows "API enabled" message)

✅ **Done! 1 of 3 complete**

---

### Step 5: Enable Street View Static API

**Go back to library or click:** https://console.cloud.google.com/apis/library

1. Type: `Street View Static API`
2. Click on **"Street View Static API"**
3. Click **"ENABLE"**
4. Wait for confirmation

✅ **Done! 2 of 3 complete**

---

### Step 6: Enable Places API

**Go back to library:**

1. Type: `Places API`
2. Click on **"Places API (New)"** (make sure it says "New")
3. Click **"ENABLE"**
4. Wait for confirmation

✅ **Done! All 3 APIs enabled!**

---

### Step 7: Wait 2-3 Minutes

Google needs time to activate the APIs across their servers.

- Grab a coffee ☕
- Check your phone 📱
- Come back in 2-3 minutes

---

### Step 8: Come Back Here and Tell Me

Once you've enabled all 3 APIs and waited 2-3 minutes, just reply:

**"APIs are enabled"**

And I'll immediately run the command to update all your places with real Google images!
